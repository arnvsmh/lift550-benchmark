# LIFT-550

Code, configuration files, and evaluation results for the paper
*Loss-Induced Regime Transitions in Wall-Bounded Turbulence Super-Resolution*
by Arnav Simha and Pranav Kulkarni.

**This repository is under construction.** Code and results will be added
ahead of publication.

## Contents (planned)
- `code/` — training, evaluation, degradation pipeline, baseline implementations
- `configs/` — per-run training configurations
- `results/` — evaluation summaries for all reported metrics
- `histories/` — per-epoch training records

## Data
The underlying DNS fields are not redistributed here and are available from the
KTH FLOW group upon request.
